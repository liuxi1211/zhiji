抽卡Gacha · /gacha · 对应核心模块定义 2.4

抽卡是全部复习机制的所在地，也是每日回访的默认锚点——「今晚先抽一把」就是打开产品的理由。 卡池 = 你已闯过关卡里的卡，按三条信号混抽：到期复测（SM-2 间隔重复主引擎）、抽查验伪（快过态与「我会，跳过」的卡低频复验）、弱点重抽（「我不会」的卡权重上调）。 它既是复习器，也是自报水分的挤压器——闯关因此可以放心纯推进。 标志性元素是牌堆：把三条不可见的混抽信号变成一摞看得见的实体牌，翻一次即从刻度进入题目。

  • 墨青 · 主色 / 翻牌 / 判定命中
  • 铜 · 只承担「刻度 / 目标停止点」语义
  • 难度 1–5 · 颜色只编码难度，三条信号一律用中性文字角标

模块 04 · LEARNING

抽卡

轻体验：翻面自评为主，橙红高难卡可选进入判定；保留翻牌动画与连抽，不引入积分、连击等游戏数值系统，不设正式报告。混抽权重按会话状态动态调整（连对降权 + 连错时掺低难度穿插卡），第一版就有。

卡池说明「只有闯过的卡才进池」卡池 = user_kp_state 中已过关知识点的集合；闯关走过的部分（2.4）
「抽卡不新增表 / 不自己造任务」说明三条信号都由闯关喂养；抽卡与闯关共享练习态，无编译依赖新增（2.4 / 2.3）
虚报证据「汇入复盘降级建议」说明简历授权卡的虚报 / 失败累积汇入复盘的降级建议（2.4）
无报告、无排名、不算积分的小结语气不设正式报告；抽卡是复习器 + 挤压器，不是竞技场（2.4）
