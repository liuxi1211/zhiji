知己 · C 端模块原型

学习地图 & 闯关Learning · /map · 对应核心模块定义 2.2 / 2.3

学习地图是 C 端日常主入口：每个技能域一个关卡组，组内按主题簇分关卡——关卡即题组，单关 3 分钟量级。 闯关纯推进、组内不回头，复测与复习全部归抽卡。双轨过关并存、用户自选： 闪卡快过（低保障通道，快过态进抽查池优先复验）与练习模式（闭卷作答，判定引擎驱动下一步）。 标志性元素是深度轴：追问链逐层下钻，铜色刻度标出目标职级的停止点——「到你目标职级讲到第 N 层算够」。

  • 墨青 · 主色 / 当前游标 / 判定命中
  • 铜 · 只承担「刻度 / 目标停止点 / 抽查」语义
  • 难度 1–5 · 白灰/绿/黄/橙/红，颜色只编码难度，来源用角标

模块 02 · LEARNING

学习地图 & 闯关

地图默认按关卡组折叠、首屏只暴露「下一步闯哪」的系统建议，关卡内容点击才展开（信息密度约束）。四信号（画像授权、职级基线、JD、复盘信号）并集裁剪题集——同一关卡组对不同用户是不同题集 + 相同题目、不同尺子。

口径对照 · 设计元素 ↔ 核心模块定义 2.2 / 2.3 与决策清单

原型中每一个非常规元素都有产品条款出处，评审时逐条核对；实现时以现行文档为准。

设计元素口径出处
「下一步 · 系统建议」铜色建议条系统给默认序：基础关组 → JD 相关 → 库级频率信号 → 授权密度；先闯哪组用户自选（2.2）
地图默认折叠 + 点开才展开组内关卡信息密度约束（决策清单 D3 记录）：默认按关卡组折叠、首屏只暴露「下一步闯哪」
锁图标 + 可见的锁原因文案跨域前置在学习地图上表现为锁：前置所在关卡组未完成到相应关卡，本组关卡上锁（2.2）
「放弃分区 · 1 题」+ 算法手撕静态说明行放弃清单 v1 手动维护；算法手撕在知识库范围外，以一行静态说明提示替代方案 LeetCode，不做成数据（2.2）
关卡行难度分布微条 + 关卡 badge关卡 = 主题簇，关卡内按难度与前置拓扑排序；难度只决定排序与卡面颜色（2.2 / 2.3）
题卡左侧难度色条 + 难度刻度；来源用 chip 角标卡面按难度配五色（1–5 ↔ 灰绿黄橙红）；颜色只编码难度，简历授权等来源信息用角标区分，不抢颜色语义（2.3）
目标刻度行「目标资深 · 讲到第 3 层算够」过关标准由知识点职级要求（下钻停止点）决定；停止点之下的层照样可见，学无止境（2.3）
深度轴：层节点 + 铜色停止点刻度 + 第 4 层虚灰可见题卡内容映射：追问入口 = 追问链按 layer_key 逐层展开；每层标方向 dir；目标刻度按当前目标职级渲染停止点（2.3）
背面三档样例：及格默认展开、良好 / 优秀折叠背面 = 标准回答样例，默认展开及格档，良好 / 优秀两档可展开（2.3）
过关四选 + 每选的去向微文案「我不会」→ 弱点加权与复测队列；「我会，跳过」→ 抽查池验伪；放弃 → 移出关卡组进放弃分区；统一写 user_kp_state（2.3）
「快过态 · 会被抽查」角标 + 快过低保障说明快过算过关推进但单独落快过态标记，进抽查池上调抽中概率，虚报打回复测队列（决策清单 D1）
「面试官在记录……」等待行练习同步判定，等待期 UI 明示；练习作答逐关判定，attempt 仅模拟考使用（2.3 / 2.5）
判定卡：答况徽标 + 命中要点 + 引用原话高亮 + 教练一句答况四分流（hit/shallow/wrong/blank）、引用强制（引不出算未命中）、missing_summary 教练口吻（附录 A 判定 JSON 契约）
四分流 → drill / rephrase / switch / fallback 四卡next_action 枚举四值：下钻 / 同层换角度 / 切题 / 回退前置；fallback 是内容层回退，不改变闯关游标（2.3）
留关提示「下次进组从这关继续」+ 切快过练习未过关的关卡留在当前关，引导看前置或从零讲；用户可随时切闪卡快过（2.3）
小结「练习判定过 / 快过」分开统计快过与练习任一过关计推进，但报告与存活率只统计练习判定数据（D1 口径）
组完成卡「解锁下游」到组末即该域完成；跨域前置以锁表达，组完成解锁依赖组（2.2 / 2.3）
「复测、抽查归抽卡，闯关只负责向前」闯关纯推进、组内不回头，复测与复习全部交给抽卡模块（2.3）
