# 知己 · 文档审核决策清单（决策索引）

> **定位声明（2026-09-23 瘦身）**：本文件只是决策过程的**索引**，不承载任何现行口径。写需求、写代码时的参考顺序固定为三层：
>
> 1. [项目企划书](项目企划书.md)——定位与方法论；
> 2. [核心模块定义](核心模块定义.md)——模块边界、表归属、枚举契约（附录 A 为真相源）；

> 拍板一项新决策只做两个动作：改对应核心文档的口径 + 在下方索引表加一行。索引与核心文档冲突时，以核心文档为准并回改索引（工程根 CLAUDE.md 开发工作流）。历史决策的完整过程记录（背景、选项、逐条分析）在 git 历史里（本文件 2026-09-23 瘦身前的版本），索引里不再展开。
