> 「我 8 年经验，其中【X】年在做搜索。现在在立创商城负责三个系统，本质是一条数据链路：代购系统把全球元器件数据采回来、加工成标准化数据底座；搜索系统让工程师在千万级数据里几秒找到要的料；详情系统承接最终转化。深度在搜索引擎——查询理解、召回排序、ES 集群治理完整做过几轮演进；广度上从 0 到 1 带过代购系统和数据加工链路。」

**「带过人吗」标准答案（诚实定位，不编管理）**：
> 「组里没有设管理岗，但新人培养实际由我负责——组里的新人都是我带的，从入职引导带到能独立扛活；另外核心方案的设计把控、线上紧急问题的处置兜底也是我在负责。如果未来往管理走，这些是基础，但我目前更倾向继续走技术深度路线。」
> 要点：带教（mentoring）≠ 管理（management）。前者是资深工程师的标配证据，编后者必穿帮——绩效、规划、汇报关系一问就露。

**个人项目的「股票」敏感度处理**：简历正文统一用「对话式数据分析 Agent（金融数据场景）」中性表述——技术细节（意图识别 / 编排 / MCP Server）先行，面试官先看到的应该是工程而不是股票；口头交流可自然说明是股票分析，兴趣驱动不扣分。投金融数据 / 行情 / 量化类公司时直接写明「股票分析 Agent」，属加分项。风险边界：全程以工程视角讲，绝不表现成「我在炒股所以懂金融」。

**两版简历提醒**：投搜索方向岗 → 项目 1 放最前、AI 检索条保留，能力区保持 1~8 顺序；投通用后端岗 → 项目 2（高并发缓存）与项目 3（从 0 到 1）前移，项目 1 压缩为 3 条，能力区同步重排：**AI 研发效能条（现第 8 条）提到第 3 位**，AI 信号前置。

**简历完整性检查（本文件之外的区块）**：
- 基本信息：姓名 / 电话 / 邮箱 / 工作年限；期望薪资不写在简历上，留到 HR 沟通再报
- 教育背景：8 年经验学历权重已下降，但统招本科是多数 JD 硬门槛，一行放简历末尾即可
